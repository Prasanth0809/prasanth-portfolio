### CloudGuard – Azure Secure Cloud Infrastructure

Enterprise-style Azure security project built across 6 phases — covering secure networking, centralized monitoring, automated alerting, custom RBAC governance, Azure Policy enforcement, and security posture management with Microsoft Defender for Cloud.

Built entirely from scratch using Azure-native services with $0 cost. Every phase is documented with screenshots, KQL queries, and architecture diagrams.

**Phase 1 & 2** — VNet + NSG + IP whitelisting + Defender for Cloud  
**Phase 3** — Log Analytics + Activity Log streaming + KQL security investigation  
**Phase 4** — Azure Monitor Alert Rules + Action Groups + email notifications  
**Phase 5** — Custom RBAC role (least privilege) + Azure Policy governance  
**Phase 6** — Microsoft Defender for Cloud security posture + compliance mapping
